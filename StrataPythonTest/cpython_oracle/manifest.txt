# CPython test files this suite draws from, one per line.
#
# Methods are not pinned individually: selector.py decides which methods in each
# file are eligible, so the set tracks CPython and Strata rather than needing hand
# maintenance. The report prints the per-file method count, so a change in
# eligibility after a CPython or front-end bump shows up in the diff.
#
# These are the LANGUAGE-level test files -- they test Python's semantics rather
# than a library. Library tests (IO, OS, networking, C internals) are out of scope:
# their assertions exercise a stdlib module Strata does not model, so the verdicts
# would carry no information about the language.
#
# The list is deliberately broad. A construct Strata cannot handle yet is a RESULT
# of this suite, not a reason to leave a file out, so files are included even when
# most of their methods are expected to come back unsupported.
